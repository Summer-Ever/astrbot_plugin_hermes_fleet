# 本插件刻意保持零第三方运行时依赖。
#
# 原因不是「不想装包」，而是三条硬约束：
# 1. AstrBot 的插件依赖装进宿主 Python，装多了会和本体或其他插件冲突；
# 2. 记忆库必须能在离线、受限环境里跑起来（SQLite 是标准库自带）；
# 3. 契约层与检索层如果依赖 pydantic / numpy，每个开发者的环境都要先对齐版本，
#    测试就不再是「拉下来就能跑」。
#
# 标准库已覆盖：sqlite3（含 FTS5）、asyncio、dataclasses、hashlib、threading。
# 唯一的可选依赖是 sqlite-vec（向量召回），装上才启用，不装退化为字面召回：
# sqlite-vec>=0.1.6
