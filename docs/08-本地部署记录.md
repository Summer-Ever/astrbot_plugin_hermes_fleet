## 部署方式：走面板的 GitHub 安装入口

**没有**手工 `git clone` 到 `data/plugins/`。原因：手工拷目录后，面板不知道这个插件
的存在（不会出现在插件列表、拿不到配置页、也没有更新来源），还得重启后端。

实际调用的是面板接口（用 `dashboard.jwt_secret` 现签一个短时效令牌）：

```
POST http://127.0.0.1:6185/api/v1/plugins/install/github
{"repository": "https://github.com/Summer-Ever/astrbot_plugin_hermes_fleet"}
```

几个容易踩的点：

- **不要用 `/plugins/install/git`**。它对 github.com 地址会直接拒绝：
  `该地址应通过 GitHub 仓库安装入口处理。` 两个端点分工不同。
- 面板接口是 `/api/plug/<插件名>/<路由>`，**不是** `/api/v1/plugins/...`。
  我第一版探测把两者混了，拿到 404，很容易误判成"接口没注册"。
- 页面 URL 带一次性 token（`/views/fleet/_t/<token>/`），不能直接拼路径访问。

## 在宿主解释器里跑的端到端冒烟

单测是在工作区 Python 下跑的，**宿主解释器是另一套环境**（3.12.12 + 插件自带包路径），
所以单独验了一遍：

```

[长期稳定信息（每轮必带）]
- 用户信息：32 岁，杭州，养了一只叫团子的橘猫，对花生过敏（严重）
[记忆使用约定] 需要回忆过去的具体细节时，先调用 search_memory 检索...
检索渲染: - 用户对花生过敏，会进急诊（#1）
stats: {'memories': 2, 'resident': 1, 'messages': 0, 'unsummarized': 0}
close 后 opened = 0；库文件与 _index.json 均可删除（无句柄残留）
```

中途遇到一次 `PermissionError: 另一个程序正在使用此文件`，查下来是**我自己的测试脚本**
写错了 API 名（`set_resident` 不存在）导致异常提前抛出、`close_all()` 没执行，
不是插件泄漏句柄。用正确 API 重跑后文件可正常删除。

## 降级链：按本机实际 provider 配，不照抄别处的 ID

面板里只有三个 provider，与 `docs/07` 里提到的 deepseek / glm 不是一台机器：

```
阿里云/qwen3.8-flash,阿里云/qwen3.7-flash,openrouter/nvidia/nemotron-3.5-super-vl:free
```

顺序理由：前两个是国内直连的 flash 档，后台总结要的是便宜与稳；免费的 nemotron
放最后兜底，因为它最可能被限流。

**这一步不能省。** `AstrBotProvider` 在"指定了 provider 但没加载到"时故意**不**静默
换模型（会把 A 模型的产出记在 B 名下），所以配置里写了不存在的 ID，后台总结会直接
失败而不是降级。热重载后 `/api/plug/<插件>/health` 读回的三段链与配置一致。
